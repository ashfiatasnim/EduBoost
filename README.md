# EduBoost

EduBoost is an AI-powered study planner that generates personalized study plans for university students using OpenAI GPT-5.5.

## Features

- Personalized study plans
- CGPA-based recommendations
- Exam preparation planning
- Lecture note analysis
- AI-generated revision schedule

## Built With

- HTML
- CSS
- JavaScript
- OpenAI API
- GPT-5.5

## How GPT-5.5 Was Used

The application sends the student's current CGPA, target CGPA, available study hours, exam timeline, and lecture notes to GPT-5.5. The model generates a customized study plan with topic priorities, time allocation, and revision suggestions.
